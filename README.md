# Procurement & Spend Analysis
### OverView
In this challenge, I am work with a procurement dataset covering purchase order activity from 2022 to 2024. The dataset includes 5,200 procurement records and brings together information across purchasing transactions, suppliers, contracts, delivery performance, invoices, payments, budgets, and savings.
